#  Netflix Homepage Clone

This is a simple Netflix homepage clone built using **HTML, CSS, and JavaScript**.  
It was created to practice frontend development, UI design, and DOM manipulation.

##  Features

- Netflix-style homepage UI 
- Responsive navigation bar
- Banner section with heading and description
- Horizontal scrollable movie sections
- Hover effects on movie posters
- Basic JavaScript scroll interaction

##  Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox & Responsive Design

- HTML is used for page structure
- CSS is used for styling and layout
- JavaScript is used for basic interactivity (navbar scroll effect)
